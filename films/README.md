# Films

Two cuts of the same 1:35 short, both scored to the same track and cut on its
beat (135 bpm, one scene every three bars).

| file | what it is | size |
|---|---|---|
| `laiba-illustrated-1440p.mp4` | hand-painted version — every photograph redrawn as an illustration, her likeness kept | 1440×2560 |
| `laiba-real-1080p.mp4` | the same film with the original photographs | 1080×1920 |

Both open on the locket, carry a couplet from Momin and one from Faraz, run
eleven portraits each with its own name, and close on `Rafay ki Zindagi`.
